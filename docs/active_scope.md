# Active scope

The sole active research question is whether a lightweight causal layer can compensate real detector latency by combining measured ego-motion geometry with object motion estimated from historical detections.

Active work is limited to:

- preserving the nuScenes real-data feasibility result and its independent reproduction and baseline-comparison analysis;
- comparing against stale, constant-velocity, Kalman, tracker, and ego-only baselines;
- external confirmation on a fixed official AV2 cohort with two detectors;
- timestamp causality, detector-only association, uncertainty-aware damping, cluster statistics, and operating-envelope analysis.

Action-conditioned detector-failure prediction, NOT-like visual residual correction, biological circuit validation, SINDY, and synthetic feasibility tables are out of scope.
