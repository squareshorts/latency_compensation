# AV2 confirmatory analysis

This directory contains the frozen AV2 cohort, official sensor payload audit,
and timestamp-valid latency-pair construction.  The 80 development, 20
model-selection, and 50 held-out logs were selected before sensor download.

Detector inference, propagation, metrics, controls, and the confirmatory
decision are not complete.  No confirmatory claim may be made from the pair
inventory alone.
